# Provider button assets

- google-g.png: official current G icon from
  https://developers.google.com/static/identity/images/g-logo.png.
- google-sans-button.ttf: Google Sans Medium, a Google Fonts API subset containing
  only the three Russian Google button labels; served by fonts.gstatic.com through
  https://fonts.googleapis.com/css2?family=Google+Sans:wght@500 with a text subset.
- discord-symbol.svg: unmodified Discord symbol linked on https://discord.com/branding,
  https://cdn.prod.website-files.com/6257adef93867e50d84d30e2/66e278299a53f5bf88615e90_Symbol.svg.

Assets are bundled locally, so buttons do not request external fonts or icons.
Google button uses the dark colors, current multicolor icon on white, Medium font
and equal prominence described at https://developers.google.com/identity/branding-guidelines.
Surrounding spacing, focus ring, settings dialog and Discord button use app tokens.
Provider names and symbols remain trademarks of their respective owners.
