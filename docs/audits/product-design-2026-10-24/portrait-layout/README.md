# Изображение у названия, связи отдельно

Главная иллюстрация личной записи перенесена из панели связей в шапку. НПС/монстр используют один экземпляр RecordIllustration вместо отдельного мобильного дубля. Игрок/локация и квест используют такую же композицию слева от названия; фото не зависит от выбранной вкладки. Связи содержат связанные записи и их миниатюры, а не портрет текущей сущности.

- Естественное соотношение сторон, contain, ограничение высоты 174 px desktop / 132 px mobile, без растягивания и обрезки. Маленькие исходники не увеличиваются. Нажатие открывает прежний полноразмерный просмотр.
- Короткие «Заменить»/«Добавить» рядом с фото имеют полные accessible names. У НПС/монстра действие открывает поля изображения в Медиа без окна, сохраняя EntityEditorController/drafts/revision. Галерея остаётся рядом с изображением.
- Нет пустой колонки в записи без картинки. Скрыт повторный портрет в подробном статблоке игрока через opt-in hidePortrait; боевые просмотры сохраняют прежний профиль.
- Заметки и магазины уже показывали изображение в основной области; их хранение/редакторы не менялись. Готовый шаблон и фон/координаты карт не изменялись.

## Проверка

Один изолированный сервер 4189 с копией «Грани Тени». Настоящие игровые записи не сохранялись. Для квеста с иллюстрацией создана отдельная локальная QA-запись; квест без собственного art также проверен.

- НПС: 6 вкладок — один портрет в шапке, ноль собственных иллюстраций в связях, один panel. 1440/1024/768/390/320 px — overflow=false. Исходный портрет 0.75 и отображаемый 130.5/174 (desktop), 99/132 (mobile) совпали.
- Игрок: пять вкладок сохраняют изображение у названия; повторный статблок после исправления имеет zero portrait. Монстр: портрет в шапке, в aside отсутствует. Локация: ratio 4:3 сохранился точно.
- QA-квест: 6 вкладок — портрет в шапке, own image в aside=0; 390 px без overflow. НПС без картинки — одна колонка шапки вместо пустого места.
- «Заменить изображение» у НПС открывает Медиа/«Ссылка на портрет» inline, dialog=0; отмена не записывает данные.

Приватные снимки находятся в игнорируемом tmp/portrait-layout; неустойчивый мобильный кадр при смене viewport отвергнут. Числовая проверка геометрии/пропорций выполнена отдельно. Web tsc/Vite/compression, test-build-manifest, test-editable-list-keys и test-workspace-routes прошли. Это frontend-правка без новых API/миграций; Go suite и платные AI-запросы не запускались.
