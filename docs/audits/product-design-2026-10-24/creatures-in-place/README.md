# НПС и монстры: редактирование на месте

Product Design + frontend-skill, выбранный вариант 3. Визуальная идея: спокойное тёмное досье с постоянным портретом, лавандовыми действиями и ясным боевым профилем. Содержание: выбор существа → одна вкладка → правка самого текста. Движение: короткое появление вкладки и отклик галереи; reduced-motion отключает эффекты.

## Аудит и изменения

- Исправлено: НПС и монстр использовали разные шапки/профили, профиль утопал во вложенных карточках. Общий CreatureWorkspace выводит основные параметры и шесть характеристик, подробные действия остаются в Статблоке.
- Исправлено: Edit открывал отдельную форму. Теперь текст редактируется в том же DOM, параметры выбираются селекторами. Шапка/вкладки/профиль не сдвигаются. Ошибка/черновик/конфликт разворачиваются только при необходимости.
- Исправлено: портрет исчезал из контекста монстра; теги и пояснения перегружали страницу. Контекст постоянен, теги и длинные пояснения раскрываются. Пояснение связи редактируется на месте.
- Исправлено: открытие редактора создавало пустые боевые/наградные профили; sanitizer отбрасывал Foundry metadata действий. Теперь отсутствие и импортированная механика сохраняются.
- Сохранены: версия записи, локальные черновики, сравнение 409, статусы, роль/локация, действия/реакции/заклинания, галерея/плейлист, карточки/зачитки, награды/проверки/цвета. Создание и просмотр иллюстрации могут использовать окно; правка существующего текста — нет. Готовый шаблон read-only.

## Проверено локально

Использован один изолированный сервер 4189 с копией «Грани Тени». Настоящие записи не изменялись; записи QA созданы в этой копии. Исходные и итоговые снимки просмотрены вместе; они остаются в игнорируемом tmp/creature-workspace, поскольку содержат пользовательскую кампанию.

- Настоящие НПС и монстр: шесть вкладок, один видимый panel, постоянный портрет/связи; console errors=0. 1440×900, 1280×600, 1024×768, 768×1024, 390×844, 320×640: overflow=false.
- Точные координаты вкладок, профиля и характеристик до/после Edit одинаковы; dialog=0 (geometry.json).
- QA монстр: Save/reload HP и STR, сохранение bold/wiki и неизменённых действий (save-proof.json). Настоящий параллельный PATCH вызвал 409: выбор собственного summary сохранил независимое серверное изменение role.
- QA НПС: восстановление черновика в новой вкладке, Save/reload; statBlock/rewardProfile остались отсутствующими. HTML-карточка сохранила цвет/bold после дописывания и Ctrl+S. Ctrl+K вставил wiki-ссылку внутрь bold без потери пробела; native Undo/Redo проверены. Теги с вводом запятой не теряют разделитель; пара связей показывает сохранённое inline-пояснение с обеих сторон (final-save-proof.json).
- Просмотр карточки игрокам → Edit закрывает просмотр и возвращает к тексту вкладки Карточки, dialog=0. После завершённого Save обычный переход не вызывает предупреждения; во время незавершённого запроса guard продолжает защищать ввод.

Сборка web (tsc/Vite/compression); test-inplace-authoring, test-build-manifest, test-device-drafts, test-entity-comparison, test-editable-list-keys, test-workspace-routes, test-reward-input, test-authoring-transport, test-workspace-responses — прошли. Go HTTP tests Authoring/Entity revision-patch/Foundry/Reward и Relations — прошли. Это целевые проверки, не полный Go suite. Существующее предупреждение Vite о крупных rules/PDF chunks остаётся.
