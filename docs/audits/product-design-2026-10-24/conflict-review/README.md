# Читаемое сравнение версий записи

Product Design, вариант 3; 24 октября 2026. Только синтетический локальный стенд.

До изменения окно показывало полные технические JSON-объекты: [до](01-json-comparison-before.jpg). Теперь оно перечисляет изменившиеся поля с двумя читаемыми вариантами, русскими подписями и явным выбором спорного поля: [desktop](02-field-comparison-desktop.jpg), [телефон](03-field-comparison-phone.jpg), [планшет](04-comparison-tablet.jpg), [низкое окно](05-comparison-short.jpg), [320 px](06-comparison-narrow.jpg). Снимки сохранены и просмотрены. Длинные значения имеют собственную прокрутку и клавиатурный фокус; технический JSON находится в отдельном закрытом раскрытии.

Независимые правки сохраняются автоматически. Если обе стороны изменили одно поле по-разному, подготовка заблокирована до выбора; изменение текста после выбора сбрасывает действительность выбора именно этого поля. Подготовка меняет только форму, запись выполняется отдельным Save. Списки и сложные профили сохраняются целиком с предупреждением, вложенное слияние не заявляется. Для старой копии без baseline различающиеся локальные поля требуют явного выбора: локальные изменения больше не пропадают из-за ошибочного принятия копии за исходник.

## Фактические проверки

- Реальный локальный сценарий: UI на revision 20, параллельный API PATCH → 21; Save → 409. Локальный title, спорный summary и server-only content показаны раздельно. До выбора Prepare disabled; после выбора и последующего редактирования summary снова disabled. Серверный вариант выбран клавиатурой Space.
- После Prepare отдельное чтение API подтвердило revision 21: подготовки недостаточно для записи. После Save и reload — revision 22, локальный title + выбранный server summary + server content; сохранены gallery 4, playlist 2, playerCards 3, spell slot 3rd/2, trait и loot. [Запись после reload](07-preserved-record.jpg).
- Восстановлена реальная старая копия revision 17; 409 показал спорный statBlock и server-only изменения других полей. Форма закрыта без записи, копия не удалена.
- 1280×720, 768×1024, 390×844, 320×720, 640×240: скриншоты проверены; на 390/640 documentWidth равен viewport. В низком окне header/footer остаются доступны, body прокручивается. Footer «Сравнить версии» переводит фокус к сравнению. Проверены radio Space и прокручиваемое значение с клавиатуры. Физический touch и полный screen-reader аудит не проводились.
- test-entity-comparison.cjs: three-way merge, явный выбор, прежний merge при известном baseline, неизвестный baseline, отсутствующие старые поля, revision, списки, false/0, длинный текст, безопасное plain-text HTML-only представление, привязка выбора к сравниваемым значениям.
- Web build, test-device-drafts.mjs, test-authoring-transport.mjs, test-workspace-responses.mjs, test-workspace-routes.mjs прошли. Manifest: 52 entries, без циклов; вход — 4 static entries без игровых chunks. Editable keys: 137 TSX, 27 editing containers, 0 прямых mutable-key проблем. После reload браузерных ошибок нет.

Изменены только web controller/component/styles, тест и документация. API/shared types/MCP, модели/стоимость AI, игровые расчёты и готовые шаблоны не менялись. Проверки backend из предыдущих выпусков не выдаются за новый прогон.

## Выпуск

Результат деплоя и соответствие файлов фиксируются в production-check.json после выпуска. Авторизованный production smoke предмета, связи и сцены остаётся отдельным обязательным пунктом: браузер production требует обычный вход пользователя. Локальные проверки его не заменяют.
