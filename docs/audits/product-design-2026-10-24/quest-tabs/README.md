## Авторизованный прогон и исправление перехода

На production 197 подтверждены Save/reload палитры «Пергамент» и compact, сохранение полного сценария и метаданных, новая встреча с количеством 2 после reload, затем изменение до 3. Настройка остаётся в URL квеста, dialog=0.

Найден дефект: открытая встреча удерживала производный editingSection=combat. При клике бокового art-редактора форма монтировалась в скрытой Media, а активным оставался Обзор. Повторный клик того же раздела также не давал нового события перехода.

Исправление: явный EntityEditorNavigation (id/section/requestId) через App → router → container → QuestWorkspace. Запрос выбирает вкладку; состояние открытости другой формы больше не управляет навигацией. Текущий EntityEditorController не пересоздаётся при повторном запросе. Нейтрально уточнено пояснение новых связей квестодателя; старые пользовательские пояснения массово не переписываются.

Локальная регрессия: открытая встреча → Обзор → sidebar Art показывает Media и редактор; Gallery → ввести caption → Сценарий → повторный sidebar Gallery удерживает текст. После Save активной остаётся Media, dialog=0. 11-navigation-fixed.jpg и navigation-check.json. Web build, manifest, device drafts, entity comparison, editable keys и workspace routes прошли; backend не менялся.
