# Общий проход рабочих страниц

Продолжение варианта 3 с Product Design и frontend-skill. Цель: один рабочий раздел за раз, компактные служебные блоки и редактирование самого текста. Короткое появление tabpanel и отклик вкладок отключаются при reduced-motion.

## Свежий аудит и изменения

1. Заметки: область текста была зажата между каталогом и связями. Выбор заметки перенесён в компактный native details с поиском; основная область стала шире. Название и Markdown редактируются на месте через общий InPlaceText, включая wiki-поиск Ctrl+K. Успешный Save/reload проверен на отдельной QA-записи.
2. События: чтение сменялось длинной формой. Теперь одни и те же заголовок, описание, дата и селекторы остаются на месте; Сцена/Варианты/Находки показывают один panel. Реплики редактируются отдельно с сохранением массива, форматирования и последствий. Селекторы имеют одинаковую высоту в обоих режимах; координаты заголовка/вкладок совпадают. Мобильные служебные действия сокращены, генерация и форматирование остаются доступны через меню.
3. Магазин: описание, секреты, галерея, ассортимент и весь каталог шли подряд. Пять вкладок разделяют задачи; по умолчанию открывается ассортимент. Одобренная иллюстрация остаётся у названия. Имя/описание/секреты редактируются на месте, Ctrl+S вызывает прежнее сохранение. Поиск каталога, добавление, количество, цены и заметки сохранены. Save/reload текста/секрета/количества проверен в QA-магазине. Ctrl+S реально выполнил повторное сохранение; временный тестовый текст затем восстановлен тем же способом.
4. Общие связи: compact и inlineEdit теперь значения по умолчанию. Длинное пояснение раскрывается отдельно и редактируется без окна. Пакетное добавление остаётся поисковым picker; серверные owner/revision/atomic guards и overlay готовых кампаний прежние.
5. Игроки и сессии: вместо вводного обещания — назначение и приглашения; сокращены отступы группы. Инструкция из пяти шагов журнала раскрывается отдельно. Пустой журнал сразу предлагает TXT, без большого центрального hero.
6. Предметы и правила: карточки предметов выравниваются внутри строки, а не по самой высокой карточке всего каталога; сокращены резервные текстовые слоты и пустоты. Механика правила читается последовательными строками вместо узких декоративных карточек.
7. Карты: сломанная миниатюра заменяется штатным значком карты. Сам фон карты, геометрия, камера и редактор не менялись.

## Проверки и границы

- 15 основных разделов: Главная, Сессии, Игроки, Квесты, Локации, НПС, События, Заметки, Магазин, Монстры, Предметы, Правила, Оффлайн, AI-чат, Карты. DOM-проход на 1440/768/390 px: горизонтального overflow нет (page-layouts.json). Это проверка рабочих начальных экранов, а не всех вложенных состояний каждого сложного редактора.
- Свежие снимки начальных экранов, настроек и изменённых состояний сохранены/просмотрены в игнорируемом tmp/all-pages. Они содержат копию пользовательской кампании и не включаются в Git. Неустойчивые снимки при смене сборки/viewport отвергнуты; рабочие проверки выполнялись после полной перезагрузки итоговой сборки.
- Синтетические QA-записи созданы только в изолированной локальной копии «Грани Тени». Серверный readback подтвердил текст заметки, сцену, обе реплики, последствия/лут, описание/секрет магазина и количество 3 (save-proof.json). Готовые шаблоны не изменялись.
- Вкладки: native roles/controls/selected, Home/End/стрелки; один видимый panel. Геометрия события до/после Edit совпадает, dialog=0 (event-geometry.json).
- Прежние transport/controllers не заменены: device drafts, PATCH expectedRevision, comparison/recovery остаются. Новых API/полей хранения/миграций нет. Платные AI-запросы не запускались, цены/модели/игровые формулы не менялись.
- Web tsc/Vite/compression и test-build-manifest, test-editable-list-keys, test-inplace-authoring, test-device-drafts, test-entity-comparison, test-workspace-routes, test-authoring-transport, test-workspace-responses прошли. Go HTTP tests Relations/WorldEvent/Shop прошли. Это целевые регрессии, не полный Go suite. Предупреждение о прежних крупных rules/PDF chunks остаётся.
