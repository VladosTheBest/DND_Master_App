# Вкладки досье и авторизованный production smoke

24 октября 2026. Цель: убрать длинную страницу после отмеченной пользователем навигации; проверить предмет, связи и сохранение сцены под обычным аккаунтом на Fly.io. Сохраняются токены/типографика варианта 3. Production проверен в Chrome с уже открытым пользователем аккаунтом; локальный стенд — отдельное JSON-хранилище. Секреты/сессии не извлекались, существующие игровые кампании не менялись.

## Изменение интерфейса

НПС, игрок и локация используют tablist/tab/tabpanel вместо якорей. Header и вкладки остаются на одном месте, виден один выбранный раздел. Иллюстрация, summary, факты и награды находятся в «Сводке», заметки мастера/карточки/медиа/квесты или магазины/связи/характеристики разделены. У связей один instance, прежние поиск, черновики и revision сохранены. Локальная смена вкладки не меняет URL/hash и не отправляет mutation; смена записи начинает со «Сводки». Характеристики сразу раскрыты. Клавиатура: один tab stop, стрелки с циклическим переходом, Home/End, Tab к содержимому. Недоступные панели hidden и не увеличивают страницу.

## Шаги и результаты

1. **Создание отдельной тестовой кампании — найден и исправлен дефект.** На release 194 создание сохранилось, но callback гидратировал новую кампанию без смены URL прежней. Возникало «Кампания недоступна»; обычный reload/переключатель открывал сохранённую кампанию. App теперь направляет на dashboard созданной кампании. Локально новая тестовая кампания сразу открылась с правильным URL и без ошибки.
2. **Предмет — исправен на production 194.** Через UI найден «Сумка с бобами» за пределами первой страницы, открыта модальная карточка, загружено полное описание и таблица эффектов. Escape закрывает окно. [Снимок](01-production-item.jpg).
3. **Связь — исправна на production 194.** В отдельной QA-кампании созданы синтетические НПС и локация; через «+» выбраны фильтр НПС, серверный поиск и пояснение. После Save/reload связь видна с обеих сторон; переход по записи работает. [Обратная связь после reload](03-production-reverse-link.jpg).
4. **Сцена — исправна на production 194.** Создан фон с комнатой в Креативе без AI-запроса. Размечены дверь и свет, дверь перенесена через координаты, проверены Undo/Redo и Fit/100%. После сохранения и полного reload сцена открылась с 4 editor walls, 1 door и 1 light. Дверь (475,330)→(400,330), свет (420,230), bright/dim 15/30 сохранены. Foundry-ready выход содержит 6 wall/door сегментов из-за разрезания стены, исходная editor geometry остаётся 4+1. [Повторное открытие](05-production-scene-reopened.jpg).
5. **Вкладки — локально исправны.** Все семь вкладок НПС: ровно один видимый panel, один tab stop, пустой hash; tablist остаётся на y=295 при всех переключениях — [tab-checks.json](tab-checks.json). Локация и игрок отдельно проверены со своими шестью вкладками. Проверены Right, Home, End; URL сохраняется. Размеры: 1280×900, 768×1024, 390×844, 640×360. На телефоне вкладки переносятся, горизонтальной прокрутки документа нет. Скрытые поля недоступны клавиатурой; полный screen-reader аудит и физический touch не выполнялись.

Загрузка локального файла через Chrome extension оказалась недоступна без отдельного разрешения расширения. Настройки доступа не менялись: проверка сцены выполнена через штатный Креатив. Это ограничение инструмента, не ошибка upload сайта. Неуспешный loading screenshot обратной связи заменён свежим принятым кадром; он не используется как доказательство.

## Проверки и выпуск

Web build и существующие scripts test-workspace-routes, test-workspace-responses, test-authoring-transport, test-device-drafts, test-entity-comparison, test-scene-editing, test-editable-list-keys, test-build-manifest прошли. 137 TSX / 27 editing containers / 0 direct mutable-key проблем; 52 manifest entries без циклов, sign-in closure 4 entries без игровых chunks. Backend/shared types/HTTP/модели и цены AI/готовые шаблоны/игровые расчёты не менялись. Новая сборка и повторный production smoke будут зафиксированы после выпуска.
