# Проверка видеосцен — 26 октября 2026

Реализованы внешние видеофоны и отдельный локальный помощник Foundry. Инструкция: ../../foundry-video-background.md.

## Фактически проверено

- Реальное извлечение предоставленного пользователем публичного YouTube-ролика: доступный вариант 1920×1080, 19 секунд. Подготовлены фрагменты 10 и 12 секунд (последний — со смещением 1 секунда), H.264 MP4 и JPEG первого кадра. Финальный pipeline выполнен с актуальным yt-dlp, FFmpeg и Node 24. Предпочтение 1440p не увеличивает исходное разрешение.
- В отдельной локальной копии кампании браузер прошёл YouTube → помощник → пауза/воспроизведение первого кадра/видео → четыре стены, дверь и свет → сохранение → повторное открытие. В DTO сохранены только URL/параметры и геометрия; нет ключа помощника и видеобайтов. Published-разметка содержит проём, исходные editorWalls сохранены.
- В отдельной копии настоящего Foundry 14.368/dnd5e импорт выполнен кнопкой модуля после подтверждённого пользователем подключения к локальному сайту. Подготовленный файл использован как нативный фон Scene/Level; стены и дверь видны в Wall Controls. Видео не содержит YouTube iframe/плеера. Сцена просматривалась через View, не активировалась для игроков.
- Повторный импорт завершён 1/1, число элементов сцены в каталоге не выросло. Помощник вернул кешированный результат после перезапуска. Реальный файловый сервер Foundry вернул 206 и ровно 1024 байта на Range-запрос.
- Штатный Export Data в Foundry подтвердил 1920×1080, шесть опубликованных линий (одна дверь), один источник света, MP4 в background первого Level и предпочтение источника 1440p. Прямая HTTPS-ссылка MP4 дополнительно открыта браузером без ключа помощника, metadata 960×540, пропорции/сетка определены автоматически; сцена сохранена.
- Приватные снимки/локальные JSON находятся в игнорируемом tmp/video-scenes. Пароли, ключи, данные подключения и содержимое реальных кампаний в этот отчёт не включены.

## Автоматические проверки

Полный Go suite apps/server, затем целевые проверки источника/CORS/auth/кеша/аргументов subprocess и API validation/JSON round-trip/revision; 97 тестов модуля Foundry; scene-editing и scene-creative; web production build. Race detector отдельно недоступен при текущем CGO_ENABLED=0 и не считается пройденным. Сохраняются прежние предупреждения Vite о больших chunks правил персонажей/PDF.

## Границы

Отдельный вход игроком и полный проход обзора токена/тумана не выполнялись: импортируются обычные native walls/lights и видеофон. Удалённый Linux Foundry с HTTPS reverse proxy отдельно не запускался; бинарный файл cross-compiled. Не проверено гарантированное получение 1440p с другого ролика, недоступного в данном источнике. Browser cache не имеет жёсткого лимита в минутах. Никакого автоматического скачивания/проксирования видеобайтов сервером сайта нет. Публичный выпуск: Fly release 205, исходники 9e7e41f, health passing. HTML и все 60 JS/CSS побайтно совпадают с проверенной сборкой; публичный ZIP модуля совпадает с локальным, манифест 0.18.0. Windows/Linux helper отдаются с правильными форматами PE/ELF и версией 0.18.0. Детали и SHA-256 — production.json. Авторизованный production smoke после этого деплоя не выполнялся.
