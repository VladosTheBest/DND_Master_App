# Проверка импорта волшебника

Проверенный стенд: текущий Go-сервер и web-сборка с отдельным JSON-хранилищем, Foundry 14.368, dnd5e 6.0.6, Shadow Edge GM 0.9.2 и отдельный Dice So Nice 5.3.4. Основной обмен и импорт используют настоящий API сайта. Только ответ истёкшего pairing (404 `pairing_expired`) подменяется для проверки восстановления; scoped snapshot остаётся настоящим. Пользовательское хранилище и рабочий мир для этого теста не используются.

`packages/foundry-module/tests/runtime-site-wizard.cjs` загружает валидный черновик волшебника D&D 2024 в браузерное автосохранение, продолжает его через интерфейс мастерской и нажимает «Сохранить в кампанию». Затем выполняет настоящее подключение через окно модуля: преждевременное завершение возвращает pending-панель и сохраняет секрет; после подтверждения кампании на сайте завершение возвращает панель без импорта документов. После reload восстанавливает подтверждённый pending pairing с истёкшим запросом через «Обновить с сайта» и настоящий scoped snapshot. Поэтому тест проверяет восстановление/сохранение готового черновика, HTTP-контракт, CORS, доступ и импорт; он не имитирует каждый отдельный клик выбора класса/заклинания.

У волшебника 5-го уровня INT 17, бонус мастерства +3, атака заклинанием +6, DC 14, 37 HP, экспертиза Магии +9. Переносятся 17 заклинаний книги и четыре текущих заговора, девять подготовленных заклинаний, бонусные записи Savant и исходные ячейки 4/3/2. Не выбранные для подготовки заклинания остаются в книге, заменённые старые заговоры не добавляются.

| Проверка | Фактический результат |
|---|---|
| Первый импорт | Совпали DC, атака, характеристики, навыки/экспертиза, HP, максимум и подготовка |
| Fire Bolt | Штатное окно атаки; +6; урон 2d10 на 5-м уровне, удвоение при native крите; кнопка урона и применение HP |
| Grease | Расход ячейки первого уровня, настоящее размещение Region, длительная анимация и очистка |
| Darkness | Расход ячейки второго уровня, настоящий эффект концентрации, петля и удаление при её окончании |
| Fireball | Ячейка третьего уровня, размещение/удаление Region, эффект перед кнопками, DC 14, 8d6 и применение HP после спасбросков |
| Shatter повышенной ячейкой | Расход ячейки третьего уровня, DC 14, 4d8 вместо базовых 3d8, применение HP |
| Shield | Расход ячейки первого уровня, настоящий +5 КД |
| Повторное обновление | Нет дублей Actor/Items; потраченные ячейки, текущие HP и эффекты сохраняются |

Исправлены три выявленных дефекта: подготовка не переносилась; дополнительные не подготовленные заклинания книги могли отсутствовать; навыки получали стандартную для schema Ловкость, а экспертиза терялась. Кроме того, первый импорт задавал максимум ячеек без текущего количества — теперь новый Actor получает полные ячейки. При обновлении они не восстанавливаются. Для уже существующих старых импортов с пустыми ячейками необходим штатный отдых/восстановление ресурсов; автоматически отличить ошибочную пустоту от реально потраченных ячеек нельзя.

Это не подтверждение полной автоматизации всей книги. Встроенный набор содержит 21 частично настроенное заклинание. Magic Missile с распределением снарядов, HP лечения, телепортация Misty Step, Counterspell/реакции, условия и повторяющийся урон длительных областей остаются native/manual. Произвольные заклинания вне набора могут получить SRD Activity, но не гарантированную анимацию или собственный боевой workflow. Передача происхождения/классовых особенностей с отдельными расходами и назначение Foundry-владельца игроку пока не универсальны. Новая разрешённая сервером проекция `spellSelection` сейчас предназначена для книги волшебника, не всех классов и источников магии.

Публичный `dnd-master-app.fly.dev` при проверке возвращал HTTP 503; authenticated Fly healthcheck подтвердил `storage_unavailable`. Production-подключение этим прогоном не подтверждено; серверные исправления не развернуты. Это отдельное ограничение от успешного локального HTTP-прогона.

Для запуска нужны `FOUNDRY_TEST_URL`, `SITE_TEST_URL`, `SITE_TEST_PASSWORD` и установленный Playwright (`PLAYWRIGHT_MODULE`, если отсутствует в стандартном Node resolution). Только отдельные тестовые stores/world. Серверный тест `TestFoundryWizardSnapshotResolvesCurrentBookAndPreparation` и adapter unit проверяют проекцию книги/подготовки и экспертизу, включая старую dnd5e 5 representation подготовки.
