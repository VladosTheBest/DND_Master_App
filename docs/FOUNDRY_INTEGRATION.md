# Foundry — ручной обмен, версия 0.2.0

Модуль находится в `packages/foundry-module`. Обмен запускает мастер двумя кнопками: «Обновить с сайта» и «Экспортировать на сайт». При загрузке мира сетевых запросов и таймера синхронизации нет. Полная цель «любой персонаж, все способности, расчёты и анимации без настройки» пока не достигнута: ниже отделены реализованные функции и оставшиеся этапы.

## Установка и подключение

1. Собрать приложение: `npm run build --workspace=@shadow-edge/web`. Prebuild создаёт ZIP в `tmp/foundry/shadow-edge-gm.zip` и копирует его с манифестом в web dist. Docker включает тот же шаг.
2. В установке модулей Foundry указать `https://<сайт>/foundry/module.json`. Сервер подставляет абсолютные manifest/download URL; ZIP выдаётся по `/foundry/shadow-edge-gm.zip`. Для production используется существующий `PUBLIC_BASE_URL`. Публикации в каталоге Foundry пока нет.
3. Зависимости устанавливаются через Foundry отдельно от нашего ZIP: Midi-QOL, Sequencer и JB2A Free. Чужой код и видеотека не встроены в пакет. Активировать модуль и зависимости в мире dnd5e.
4. Нажать Shadow Edge GM → «Подключить», указать HTTPS-корень сайта. HTTP поддержан для localhost. На открытой странице войти в кабинет, выбрать свою кампанию и подтвердить подключение. Вернуться в Foundry → «Завершить подключение» → «Обновить с сайта».
5. «Настроить расчёты» применяет профиль Midi-QOL после подтверждения мастером. Предыдущий ConfigSettings сохраняется в настройке мира нашего модуля; есть кнопка восстановления. Эти настройки общие для мира.

Целевой манифест: Foundry 14.368+, dnd5e **5.3.3**, Midi-QOL **14.0.13**, Sequencer **4.2.3**, JB2A Free **0.9.4**. Это кандидат для совместного тестирования, не подтверждённая нашим runtime-тестом связка; поле `verified` в нашем манифесте не задано. dnd5e 6 пока не поддержан. Основание выбора: [Midi-QOL](https://foundryvtt.com/packages/midi-qol/), [Sequencer](https://foundryvtt.com/packages/sequencer), [релиз Foundry 14.368](https://foundryvtt.com/releases/14.368). Установленная локальная связка 14.360 / dnd5e 5.3.0 использована только в отдельном тестовом профиле с ослабленным тестовым манифестом; основной профиль не обновлялся.

## Реализованный обмен

| На сайте | В Foundry / обратный перенос |
|---|---|
| Игроки и нативные листы конструктора | Character Actor; характеристики, максимальные HP, AC, скорость, класс, владения навыками/спасбросками, ячейки и выбранные заклинания. Экспорт изменений нативного Actor создаёт внешний лист у связанного игрока, сохраняя выборы конструктора. |
| NPC и монстры | NPC Actor, прототип токена и отдельная закрытая GM-заметка. Редактор способности задаёт атаку, спасбросок, лечение или урон, активацию, дальность, тип урона и фиксированный DC. Понятные численные атаки преобразуются автоматически; текстовые/неоднозначные способности остаются ручными. |
| Локации, квесты, лор, события, магазины, подготовка | Закрытые JournalEntry. Изменённые тексты возвращаются в исходную запись. Новым журналам мастер выбирает тип. HTML экспортируется простым текстом. |
| Карты мира | Неактивная Scene с исходным фоном и редактируемыми Drawing-подписями. Перенос текста, позиции, размера, шрифта, цвета и поворота в обе стороны; новые текстовые Drawings возвращаются подписями. Изгиб, ширина дуги, жирность, курсив и обводка сохраняются в metadata, но их оформление в Foundry пока не воспроизводится. |
| Карты сессий | Постоянная библиотека сайта: этажи, фон, размеры, сетка, стены/двери. В Foundry каждый этаж — отдельная Scene с фоном, стенами и сеткой. Существующие данные крыш сохраняются; работу над крышами исключили из текущего плана. |
| Новые Actor, Scene, Journal | Выбор в предпросмотре; новые документы по умолчанию не отмечены. Медиа копируется из хранилища Foundry на сайт, новые ID закрепляются сервером. |

Экспорт исключает текущие HP, потраченные ячейки/ресурсы, эффекты, макросы, combat, туман войны и текущий токен. Состояние открытой двери не считается постоянным изменением. Все Actor получают безопасную публичную биографию; GM-текст хранится отдельно. Удаление источника не удаляет документ Foundry. Подготовленная кампания остаётся неизменяемым шаблоном; экспорт её сюжета, NPC и карт мира блокируется, игроки и отдельные карты сессий разрешены.

Изменения сайта и Foundry сравниваются с сохранённой базой. Независимые поля применяются вместе; конфликт показывает выбор версии. Импорт не меняет Actor во время начавшегося боя. Экспорт требует серверного preview, повторно сверяет hashes при commit, сохраняет весь пакет атомарно и защищает повтор requestId от дублей. Assets загружаются перед окончательным подтверждением пакета: отмена может оставить неиспользуемый файл загрузки. Удаления, автоматическая конверсия отношений в UUID-ссылки и перенос произвольных эффектов/Activities не поддержаны.

## Доступ и хранение

Подключение выдаётся владельцем одной кампании, привязано к Origin Foundry и отзывается на `/foundry/connect`. В браузере мастера IndexedDB хранит секрет подключения, исходные записи и базу сравнения; в мире/flags нет bearer-секрета. Смена браузера требует подключения заново. Сервер хранит SHA-256 секрета, owner/campaign/origin и квитанции идемпотентности. Pairing и preview живут в памяти 5 минут. Подтверждение pairing требует cookie; bearer не принимается обычными маршрутами сайта. Разрешён CORS для Origin подключения без credentials. Медиа читается только из namespace своей кампании либо встроенного разрешённого шаблона, без загрузки произвольных внешних URL сервером.

JSON: `foundryConnections`, `foundryReceipts`, `campaign.sessionMaps`, `entity.foundryCharacter`. PostgreSQL migration 7: `foundry_connections` и `foundry_receipts`; maps/external sheets остаются внутри campaign JSONB. Cloud codec включает новые коллекции; обычные редактирования карточек сохраняют внешний лист.

Безопасный профиль механики хранится в `statBlock.actions/bonusActions/reactions/traits[].foundry`, во внешнем листе — `items[].mechanics`. Профиль содержит тип действия, активацию, дальность в футах, ближнюю/дальнюю атаку, способность/DC спасброска, половину/отсутствие урона при успехе и тип урона; формула и бонус используют прежние поля записи. Экспорт читает настоящую коллекцию Activities dnd5e. Поддержана одна простая Activity с одним компонентом урона/лечения и фиксированными числами. Масштабирование, расход ресурсов, эффекты, несколько Activities/компонентов и вычисляемые бонусы возвращаются как `manual`; исходный текст сохраняется, полная механика таких документов не восстанавливается. Скрипты и макросы не передаются. Обновление старой базы импорта выполняется один раз при переходе на адаптер 2; несохранённые на сайте местные изменения остаются кандидатами экспорта.

| Метод | Путь | Доступ |
|---|---|---|
| GET | `/foundry/connect` | Страница входа/подтверждения и отзыва |
| GET, HEAD | `/foundry/module.json`, `/foundry/shadow-edge-gm.zip` | Публичные артефакты сборки |
| POST | `/api/integrations/foundry/pairings` | Origin Foundry, hash клиентского секрета |
| GET | `/api/integrations/foundry/pairings/{id}` | Секрет pairing + точный Origin |
| POST | `/api/integrations/foundry/pairings/{id}/approve` | Cookie владельца + доверенный Origin |
| GET / DELETE | `/api/integrations/foundry/connections` / `connections/{id}` | Cookie владельца |
| GET | `/api/integrations/foundry/v1/snapshot` | Campaign-scoped bearer, ETag |
| POST | `/api/integrations/foundry/v1/export/preview`, `export/commit` | Campaign-scoped bearer |
| GET / POST | `/api/integrations/foundry/v1/assets?url=...` / `v1/assets` | Campaign-scoped bearer; POST multipart `file` |
| GET, POST | `/api/campaigns/{c}/session-maps` | Cookie владельца |
| GET, PUT, DELETE | `/api/campaigns/{c}/session-maps/{id}` | Cookie владельца; PUT требует revision |

## Автоматизация и оставшиеся этапы

Подготовлены профили для Fire Bolt, Ray of Frost, Magic Missile, Cure Wounds, Healing Word, Burning Hands, Fireball, Lightning Bolt, Bless, Shield. Заклинания клонируются из SRD compendium dnd5e своей редакции; оригинальные документы не меняются. Sequencer запускает доступный JB2A эффект после Midi RollComplete, подавляя повтор того же workflow на одном клиенте. Недоступная анимация не прерывает расчёт. Импортированные способности маркируются `partial`/`manual`; панель показывает их количество. **Ни одному профилю пока не присвоено полное проверенное покрытие.**

Продолжение плана:

1. Проверить целевую связку 14.368/5.3.3/Midi/Sequencer/JB2A в отдельном мире: атака, save, AoE, лечение, расход/восстановление ресурсов, концентрация, повторяющиеся эффекты, реакция Shield, бонус Bless, условия и права player/GM. После успешных сценариев закрепить `verified` и покрытие конкретных действий.
2. Расширить реализованный редактор и безопасный DTO: цели/AoE, масштабирование, расход, длительность, концентрация и эффекты с проверкой реальных сценариев. Сейчас внешний лист не восстанавливает полную механику произвольного Actor.
3. Дополнить оформление подписей мировых карт и преобразование ссылок между сущностями в UUID, проверить большие карты. Крыши отложены по решению пользователя; bitmap mask сейчас в библиотеку не входит.
4. Расширять покрытие заклинаний и классов по подтверждённым сценариям, затем выпустить пользовательский пакет. Развёртывание сайта/облачная миграция и публикация в каталоге ещё не выполнены.

## Проверки

- `go test ./apps/server/...`: backend, включая scoped access, revocation, preview/commit/replay, конкурентный конфликт, откат ошибки записи, JSON/cloud codec, сохранение private map metadata, routes/download и revision CRUD карт.
- `npm run test --workspace=@shadow-edge/foundry-module`: merge, ручные неопределённые атаки, редакции, координаты, исключение runtime-полей, отсутствие API-запросов/таймеров при загрузке мира.
- `npm run build --workspace=@shadow-edge/web`: TypeScript/Vite и сборка ZIP.
- `packages/foundry-module/tests/runtime-smoke.cjs`: настоящий disposable Foundry world, мок только API сайта. Импорт NPC/Activities, отсутствие дубля при повторном обновлении, отсутствие экспорта изменения текущих HP, экспорт переименования/постоянных HP, разделение GM-текста. Нужны `FOUNDRY_TEST_URL` и установленный Playwright (опционально `PLAYWRIGHT_MODULE`). Нельзя запускать против рабочего мира.
- Дополнительный локальный smoke создал/удалил настоящие Scene со стеной-дверью и JournalEntry с закрытым ownership. Проверки Midi-QOL, анимаций и player-клиента пока нет.
- `packages/foundry-module/tests/runtime-extensions.cjs`: в том же disposable мире проверяет настоящий save/heal/ranged attack, DC/дальность/формулу, повторный импорт внешнего DTO, подписи без дублей и слияние местного текста/позиции с изменением сайта. Координаты допускают округление Drawing до пикселя. API сайта здесь не вызывается.
- `scripts/test-foundry-mechanics-ui.cjs`: изолированный браузерный редактор, переключение save → heal → auto и сохранение/сброс профиля. Go регрессия проверяет preview/commit, обычный CRUD, перезапуск JSON и отказ некорректным профилям.
