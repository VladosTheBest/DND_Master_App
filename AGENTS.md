# Правила работы агентов

Эти инструкции действуют для всего репозитория.

1. **Перед началом работы обязательно прочитай [PROJECT_CONTEXT.md](PROJECT_CONTEXT.md).** Это краткая карта текущей реализации. Затем изучи исходники затрагиваемого участка; при расхождении кода и обзора ориентируйся на код и исправь обзор.
2. **После выполнения задачи, до финального ответа, обязательно проверь и актуализируй PROJECT_CONTEXT.md.** Отрази изменения назначения модулей, архитектуры, потоков, хранения, доступа, интеграций, HTTP-маршрутов, запуска, проверок и ограничений в соответствующих разделах. Если задача не меняет описанное состояние, проверь соответствие и не добавляй формальные записи. Это обязательный критерий завершения задачи, а не рекомендация.
3. Поддерживай компактное описание **текущего состояния**, позволяющее следующему агенту быстро войти в проект. Заменяй устаревшие сведения; не накапливай журнал действий, историю каждой правки или дубли исходников. Непрерывно обновлять обзор в процессе работы не требуется.
4. Перед завершением проверь существование указанных файлов, а при изменениях API — методы, пути, обработчики, доступ и соответствующие клиенты. В финальном ответе кратко укажи, что обзор обновлён либо проверен без необходимости изменений, и какие проверки фактически выполнены. Для чисто документальных изменений новые тесты не нужны.
5. Сначала проверь рабочее дерево и сохрани уже существующие изменения пользователя и других исполнителей. Не перезаписывай параллельно появившиеся материалы без сверки. Меняй README, поведение приложения и данные только в рамках поставленной задачи.
6. Не помещай в документацию секреты, значения cookie, ключи, рабочие токены публичных ссылок, содержимое пользовательских кампаний и анкет. Схемы описывай по исходникам, настройки — именами переменных и безопасными значениями по умолчанию. Не запускай второй сервер на том же JSON-хранилище для проверки.

AGENTS.md задаёт постоянные правила агентам, которые читают и соблюдают этот файл. Он сам не запускает синхронизацию документации и не гарантирует её выполнение произвольными внешними инструментами.
